# 🗺️ Интерактивная карта АЗС с наличием топлива

[![GitHub last commit](https://img.shields.io/github/last-commit/piterkey/azs)](https://github.com/piterkey/azs/commits/main)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> Интерактивная веб-карта автозаправочных станций (АЗС), отображающая наличие топлива, цены и позволяющая фильтровать по различным параметрам. Страница автоматически загружает данные из API Альфа-Банка и отображает их на OpenStreetMap.

**🌐 [Демо-версия](https://piterkey.github.io/azs/)**

[English](#-interactive-map-of-gas-stations-with-fuel-availability) | **Русский**

## ✨ Возможности

*   **Интерактивная карта** — визуализация АЗС на OpenStreetMap с цветовой индикацией наличия топлива.
*   **Поиск по адресу** — автоматическое определение координат по введённому адресу (город, улица, дом).
*   **Фильтрация**:
    *   По радиусу поиска (с прогрессивным шагом).
    *   По количеству ближайших станций.
    *   По типу топлива (АИ-92, АИ-95, АИ-98/100, ДТ).
    *   По бренду АЗС.
    *   По статусу наличия топлива (Есть, Нет, Вероятно нет и др.).
*   **Сортировка** — по расстоянию, адресу, цене, дате обновления.
*   **Гибкий источник данных** — возможность указать любой URL с JSON-данными, загрузить локальный файл `stations.json` или использовать репозиторий GitHub как резервный источник.
*   **Адаптивный дизайн** — корректное отображение на ПК, планшетах и мобильных устройствах.
*   **Тёмная тема** — комфортный просмотр в любых условиях.
*   **Интернационализация (i18n)** — полный перевод интерфейса (русский/английский).

## 📦 Установка и запуск

### Локальный запуск

1.  Скачайте файл `index.html` одним из способов:
    *   Нажмите на ссылку **"Скачать актуальную версию index.html"** внизу страницы.
    *   Используйте функцию браузера **"Сохранить как"** (Ctrl+S / Cmd+S).
2.  Для наилучшей работы рекомендуется запустить локальный веб-сервер (например, с помощью Python: `python3 -m http.server 8000`). Это позволит странице загружать файл `stations.json`, если он находится в той же папке.
3.  Вы также можете открыть скачанный файл напрямую в любом современном браузере (Chrome, Firefox, Safari, Edge).
4.  Страница будет пытаться загрузить данные в следующем порядке:
    1.  **Локальный файл** (`stations.json` в той же папке).
    2.  **API Альфа-Банка** (источник по умолчанию).
    3.  **Репозиторий GitHub** (резервный источник).

### Файл данных

*   Вы можете разместить файл `stations.json` рядом с `index.html`. Страница загрузит данные из него в первую очередь (при запуске с веб-сервера).
*   Файл `stations.json` имеет размер **> 20 МБ** и автоматически обновляется в репозитории.
*   Также вы можете использовать кнопку **"Загрузить JSON"**, чтобы вручную выбрать любой JSON-файл.

## 🔧 Использование

### Основные элементы управления

1.  **Адрес** — введите адрес для быстрой навигации к точке.
2.  **Координаты** — ручной ввод координат (широта, долгота).
3.  **Радиус** — слайдер или числовой ввод с прогрессивным шагом.
4.  **Количество станций** — ограничение числа отображаемых станций.
5.  **Тип топлива** — выбор отображаемого типа топлива.
6.  **Бренд** — фильтр по бренду АЗС.
7.  **Наличие топлива** — выбор нескольких статусов.

### Управление картой

*   **Клик** по карте — установка новой точки отсчёта (в режиме "Указать центральную точку на карте").
*   **Клик** по маркеру станции — просмотр информации о станции и подсветка в таблице.
*   **Клик** по строке таблицы — подсветка станции на карте и открытие её попапа.

### Загрузка данных

*   **Обновить** — загрузить данные с текущего URL.
*   **Загрузить JSON** — вручную загрузить JSON-файл с данными.
*   **URL данных** — возможность указать альтернативный источник данных.

## 📊 Источник данных

Источник данных по умолчанию — API Альфа-Банка:
`https://alfabank.ru/api/v1/azs-stations/public/stations`

Данные включают:
*   Название и бренд АЗС.
*   Адрес и координаты.
*   Наличие и цены на топливо.
*   Время последнего обновления.

## 🗺️ Технологии

*   **Leaflet.js** — библиотека для интерактивных карт.
*   **OpenStreetMap** — тайлы карты.
*   **Nominatim** — геокодирование (поиск по адресу и обратное геокодирование).
*   **Vanilla JavaScript** — без дополнительных фреймворков.
*   **CSS Variables** — кастомизация темы.

## 📱 Адаптивность

Интерфейс оптимизирован для:
*   Настольных компьютеров.
*   Планшетов.
*   Мобильных телефонов.

## 🔒 Конфиденциальность

*   Все данные загружаются напрямую в браузере.
*   Данные не сохраняются на сервере.
*   Координаты и адреса не передаются третьим лицам.
*   Используются только публичные API (OpenStreetMap, Nominatim).
